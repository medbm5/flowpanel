# Flowpanel evals

Golden datasets (synthetic) and a stdlib-only runner that scores the AI features end to end through the backend API.

| Dataset | Cases | Metrics |
|---|---|---|
| `datasets/intake.jsonl` | 21 emails | `intake.field_accuracy` (per field, tolerant to formatting) |
| `datasets/invoice.jsonl` | 16 invoices | `invoice.line_accuracy`, `invoice.total_accuracy` |
| `datasets/copilot_rag.jsonl` | 22 questions (2 unanswerable) | `rag.hit_rate`, `rag.citation_validity`, `rag.answer_accuracy`, `rag.faithfulness` (with `--judge`) |
| `datasets/copilot_tools.jsonl` | 16 questions | `tools.choice_accuracy`, `tools.answer_accuracy` |

```bash
make eval                                            # throwaway DB + backend in mock profile, then the full suite
python -m evals run --suite all --base-url http://localhost:8080   # against a running backend (resets the demo first)
python -m evals run --suite rag,tools --judge        # LLM-as-judge faithfulness, needs OPENAI_API_KEY
```

Thresholds live in `thresholds.yaml`; any metric below its threshold makes the command exit 1 (the CI gate).
The run writes `evals/report.json` and posts the scores (with the git SHA) to `POST /admin/evals/runs`, shown on the admin dashboard.
In the mock profile the suite is deterministic. Datasets are generated by `build_datasets.py` and committed.
