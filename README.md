# Flowpanel

**From the first email to the last invoice, one workflow.**

Flowpanel is a mini vendor management system (VMS) for temporary staffing. Each mission moves through a phase-gated
workflow (Intake → Sourcing → Contracts → Timesheets → Invoice → Closed), with an AI layer that extracts, ranks,
explains and drafts while deterministic rules make every decision and a person approves.

> Demo project built for a job application. Not affiliated with Pixid. All data is synthetic.

## Stack

- **Backend**: Java 21, Spring Boot 3.5, Spring AI 1.1 (OpenAI), PostgreSQL 16 + pgvector, Flyway
- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, Framer Motion
- **Evals**: Python CLI with golden datasets, run as a CI gate
